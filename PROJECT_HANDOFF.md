# Gourmeta

## Запуск из папки site

Скопируй папку `site` целиком. В ней находятся WordPress, медиа, настройки Docker, снимок базы и материалы фирменного стиля. На новом устройстве запусти Docker с Linux-контейнерами и выполни команду из папки `site`.

```sh
docker compose up -d --wait
```

Сайт откроется на <http://127.0.0.1:8187/>, админка на <http://127.0.0.1:8187/wp-admin/>. Данные входа в локальную админку хранятся в `local/secrets/wp-admin-username.txt` и `local/secrets/wp-admin-password.txt`. Для запуска нужен свободный порт `8187`.

При первом запуске MariaDB создаёт том `gourmeta-local_database` и импортирует `local/database/gourmeta.sql`. При повторном запуске сайт использует данные существующего тома. Если на новом устройстве уже есть одноимённый том Gourmeta, автоматический импорт в него пропускается.

## Перенос после дальнейших правок

Пока Docker-проект запущен, выполни команду обновления дампа из папки `site`.

```sh
docker compose exec -T db sh /usr/local/bin/gourmeta-export-db
```

После сообщения `Updated local/database/gourmeta.sql` скопируй папку `site` целиком. Команда заменяет снимок после успешного экспорта и проверки файла. Дамп и локальные реквизиты находятся вне веб-корня и исключены из Git. Для переноса используй приватную копию папки.

Остановить проект можно командой `docker compose stop`.

## Публичная копия на GitHub Pages

[Демо Gourmeta](https://renat1144.github.io/gourmeta/) собирается из публичных страниц запущенного локального WordPress и публикуется из ветки `gh-pages`. Файлы в этой ветке сгенерированы автоматически. Для обновления снимка запусти WordPress, затем выполни команду с Python 3.10 или новее и установленными `lxml` и `Pillow`. Последний аргумент указывает на пустую папку вне публикуемых исходников.

```sh
python local/export-pages.py ../gourmeta-pages-export
```

Экспорт читает публичные карты сайта и навигацию. Демо содержит HTML, стили, шрифты и медиа, на которые ссылаются страницы. Формы и серверное сравнение оборудования ведут на основной сайт. Устаревшие ссылки каталога в демо ведут в действующие разделы. Из снимка убраны два недоступных изображения, одна загрузка Gourmeta и одна внешняя картинка L’OR.
